# Marks of other companies

These files are the official marks of products Teamwright works with. They
are trademarks of their owners and are not covered by the license of this
repository. They are here, unaltered, only to show which product an
integration is for. Teamwright is not endorsed by any of these companies.

| File | What it is | Where it came from (17 November 2026) |
| --- | --- | --- |
| `github-mark.svg` | The GitHub mark, black | <https://brand.github.com/GitHub_Logos.zip> |
| `github-mark-white.svg` | The GitHub mark, white | <https://brand.github.com/GitHub_Logos.zip> |
| `google-drive.png` | The Google Drive product icon | Google's Workspace branding files, linked from <https://knowledge.workspace.google.com/admin/getting-started/brand-your-internal-communications-with-google-workspace> |

Rules that bind every use:

- A mark is never recoloured, redrawn, stretched or given an effect.
- It stands on a plain ground with clear space around it, smaller than
  Teamwright's own name, and never as Teamwright's own logo.
- The names are written as their owners write them: GitHub, Google Drive.
- GitHub's rules: <https://brand.github.com/foundations/logo>. Google's:
  <https://about.google/brand-resource-center>.

Slack's mark is not here: Slack hands it out only to people signed in to
its media kit. Slack is named in words.
